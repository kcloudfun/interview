# interview
本项目的功能是结合代码记录面试题。

# 其他目标
1.尽可能方便调试，让开发者能亲身感受代码运行结果，而不是一段互相复制、真假不明的代码块。
2.有前端界面，即使不实际调试代码，也能有界面能看题目的文字总结。

# 项目整体代码结构
按包进行归类，一个面试题就是一个独立的小包，每个小包都有个A.java文件，该文件是对问题的总结，其他Java文件则是辅助说明。
小包再往上的包就是上级所属分类，暂时分为算法（algorithm）、Java基础（base）、JVM、多线程并发（multiThreading）、Spring框架这几个顶级分类。
